## MODIFIED Requirements

### Requirement: 进入直播间页面与分享

Vue MUST 支持直接打开并刷新 `/rooms/{roomId}`。未登录时 MUST 保留当前房间地址，登录成功后加载同一房间。详情成功后页面 MUST 展示标题、返回个人主页、复制链接、16:9 直播画面占位区和独立弹幕面板，移动端上下排列，页面隐藏用户 ID。只有属于当前路由和当前会话的响应才可更新页面。

#### Scenario: 从个人主页进入并分享

- **WHEN** 房主点击「进入直播间」并复制链接
- **THEN** 页面显示对应房间，复制内容使用该房间 UUID 并反馈结果，其他有效登录用户可打开该链接

#### Scenario: 从分享链接登录并刷新

- **WHEN** 未登录用户通过房间链接进入，完成登录后刷新
- **THEN** 登录和刷新均在原地址继续，恢复会话后请求并展示该房间

#### Scenario: 房间页失败与重试

- **WHEN** 房间链接无效、房间不存在或详情读取暂时失败
- **THEN** 页面展示对应提示。前两种情况提供返回个人主页入口，暂时失败保留房间地址并支持重试

#### Scenario: 路由或会话切换

- **WHEN** 旧请求发出后切换房间或登录会话，旧响应晚于切换返回
- **THEN** 当前页面只展示当前路由与会话对应的房间信息

#### Scenario: 弹幕连接故障时保留房间操作

- **WHEN** 房间详情已成功加载，但弹幕连接建立失败或断开
- **THEN** 弹幕面板展示连接状态及适用的恢复入口，房间标题、复制链接与返回个人主页仍可用
