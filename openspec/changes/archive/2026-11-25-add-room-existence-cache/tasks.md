- [x] 1.2 验证 TTL、租约、等待上限、回源速率和并发配置。约束缓存命令等待及断线排队，并验证缓存连接失败时可进入降级，应用的现有入口就绪仍可用。

## 2. 共享缓存、回填与回源

- [x] 2.1 增加房间存在性缓存端口和 Redis 适配，定义正命中、负命中、未命中和故障。按 [Key 约定](../../../../docs/design/room/storage.md#key-和生命周期) 实现环境隔离、同槽键和随机 TTL，验证命中不续期且非预期值不映射为房间不存在。
- [x] 2.2 用 Lua 实现双检读取与租约获取、按令牌回填及释放。负缓存截止从 Redis 取得租约时起算。验证旧令牌、租约过期、已越过负截止、写入超时以及租约接任。
- [x] 2.3 在申请 MySQL 连接前落实每实例共享的令牌桶和在途许可。调用原有 `RoomMapper.exists()`。覆盖突发、匀速、额度拒绝、查询异常、请求提前结束和真实查询完成后的额度释放。
- [x] 2.4 将 `RoomService.exists()` 接入缓存、带抖动的有界等待、缓存故障及旁路时的本机在途合并。验证等待者超时未重复查库，缓存故障下同实例同 UUID 共用结果，跨模式共用回源额度，未知结果不写为负缓存。

## 3. 创建事务和弹幕调用

- [x] 3.1 在创建事务确认提交后对最终 UUID 预热，以相同 Lua 操作写正值并使旧回填租约失效。覆盖旧负结果晚到、预热失败仍返回 `201`、事务回滚或结果未知无提前写入，以及负结果不因晚回填延长。
- [x] 3.2 核对 Ticket 签发与原子兑票、历史及新发送走同一房间检查。验证 HTTP 的 `404`、`503` 和 WebSocket 的 `1008`、`1011`。核对已有预约、回执作用域、历史阻断和连续水位仍按 [弹幕规格](specs/room-messages/spec.md) 处理。
- [x] 3.3 验证房间检查失败时发送不创建预约、不扣账号冷却、不调用生产者。区分容量或等待拒绝与 SQL 依赖失败，在现有发送熔断测试中核对许可归还及有效样本统计。
- [x] 3.4 为新增或调整的跨层 Java 方法补齐职责、参数、返回值及适用的异常说明，为 Lua 的令牌比对、负截止、事务提交边界和在途许可释放添加关键注释。

## 4. 观测、发布与三实例复测

- [x] 4.1 记录正负命中、查询合并、等待超时、回填和预热失败、实际回源速率与在途数、容量拒绝及 SQL 耗时。验证标签按实例、操作和结果聚合。
- [x] 4.2 核对最终配置与文档，走通逐台旁路发布、逐台启用和旁路回退。验证关闭缓存后的回源预算仍生效，房间表、索引和既有业务 Redis 数据无需迁移。
- [x] 4.3 运行后端测试和真实 MySQL、Redis 集成回归，覆盖房间创建、详情、Ticket、发送、回执和历史。通过现有前端构建与房间连接冒烟核对接口兼容性。
- [x] 4.4 按每组 300 次、三台合计 60 并发复测相同不存在 UUID、不同 UUID 和同一热点 UUID 到期。统计实际存在性 SQL。健康条件下每个冷热门或重复负缓存组只回源一次，热缓存阶段为零。追加租约持有者失效及迟到结果验证。
- [x] 4.5 单独停启缓存 Redis，验证真实会话、业务 Redis 和已有回执可用，统计三台回源预算、HTTP 状态和恢复后回填。用历史查询和发送冷却作对照，分别记录存在性、发送者资料及历史快照 SQL。按 [基线口径](../../../../docs/design/room/storage.md#基线与对照场景) 记录环境和结果。
